
# 🤖 Xhosa-bot

> English ↔ isiXhosa Translator Bot

Molo! This is a simple translation bot that translates between English and isiXhosa.

### ✨ Features
- English to isiXhosa translation
- isiXhosa to English translation
- Simple web interface
- Works on phone & PC

### 🚀 How to use (live)
1. Type English text
2. Click "Guqulela"
3. Get isiXhosa translation

### 🛠️ Tech stack
- Python + Flask
- deep_translator (Google Translate)
- Gunicorn for deployment

### 📦 Local setup
```bash
pip install -r requirements.txt
python app.py
